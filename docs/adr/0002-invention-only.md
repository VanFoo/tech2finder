# T2 blueprints are obtained by invention only

Every T2 blueprint is modelled as invented from a T1 blueprint copy, so each one carries a probability-weighted expected cost. T2 BPOs — originals from long-retired lottery drops — are out of scope entirely: not deferred, not modelled.

Modelling T2 BPOs would mean supporting a zero-blueprint-cost path that applies to a handful of items almost nobody has, at the price of a second code path through the entire cost model.
